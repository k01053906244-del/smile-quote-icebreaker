# 명언 보상 모달 UI 레이아웃 설계

본 명세서는 신규로 추가될 '오늘의 미소 보상 명언' 모달의 HTML 구조와 스타일 지침을 정의합니다.

## 1. HTML 마크업 구조
```html
<div id="quoteModal" class="quote-modal-overlay" style="display: none;">
    <div class="quote-modal-card">
        <div class="quote-modal-icon">🎁</div>
        <h2 class="quote-modal-title">오늘의 미소 보상 명언</h2>
        <hr class="quote-divider" />
        <div class="quote-content-box">
            <p id="quoteKo" class="quote-text-ko"></p>
            <p id="quoteEn" class="quote-text-en"></p>
            <p id="quoteAuthor" class="quote-author"></p>
        </div>
        <button type="button" class="btn quote-close-btn" onclick="window.closeQuoteModal()">
            기분 좋게 하루 시작하기 😊
        </button>
    </div>
</div>
```

## 2. CSS 스타일 시트 설계
기존의 유리 질감 테마와 통일감을 형성하면서도, 팝업 시 시선을 몰입시킬 수 있는 어두운 반투명 블러 스타일을 적용합니다.

```css
/* 모달 전체 오버레이 배경 */
.quote-modal-overlay {
    position: fixed;
    top: 0;
    left: 0;
    width: 100%;
    height: 100%;
    background: rgba(15, 23, 42, 0.85); /* 딥 퓨전 네이비 반투명 */
    backdrop-filter: blur(20px);
    z-index: 10000; /* 스마일 게이트웨이(9999) 바로 위에 안착 */
    display: flex;
    align-items: center;
    justify-content: center;
    transition: opacity 0.5s ease;
}

/* 모달 카드 바디 */
.quote-modal-card {
    width: 90%;
    max-width: 480px;
    background: rgba(255, 255, 255, 0.04);
    border: 1px solid rgba(255, 255, 255, 0.1);
    border-radius: 28px;
    padding: 35px 25px;
    text-align: center;
    box-shadow: 0 20px 50px rgba(0, 0, 0, 0.5);
    animation: quotePop 0.5s cubic-bezier(0.175, 0.885, 0.32, 1.275);
}

/* 명언 팝업 애니메이션 */
@keyframes quotePop {
    from {
        opacity: 0;
        transform: scale(0.8) translateY(30px);
    }
    to {
        opacity: 1;
        transform: scale(1) translateY(0);
    }
}

.quote-modal-icon {
    font-size: 2.5rem;
    margin-bottom: 10px;
    animation: bounce 2s infinite;
}

.quote-modal-title {
    font-family: 'Outfit', sans-serif;
    font-weight: 800;
    font-size: 1.5rem;
    background: linear-gradient(to right, #facc15, #f87171);
    -webkit-background-clip: text;
    -webkit-text-fill-color: transparent;
    margin-bottom: 15px;
}

.quote-divider {
    border: none;
    height: 1px;
    background: linear-gradient(to right, transparent, rgba(255, 255, 255, 0.2), transparent);
    margin-bottom: 20px;
}

.quote-content-box {
    margin-bottom: 25px;
    padding: 10px;
}

/* 한글 명언 텍스트 */
.quote-text-ko {
    font-size: 1.25rem;
    font-weight: 700;
    line-height: 1.6;
    color: #f8fafc;
    word-break: keep-all;
    margin-bottom: 12px;
}

/* 영어 명언 텍스트 */
.quote-text-en {
    font-size: 0.95rem;
    font-style: italic;
    line-height: 1.5;
    color: #94a3b8;
    word-break: keep-all;
    margin-bottom: 15px;
}

/* 저자 명세 */
.quote-author {
    font-size: 0.85rem;
    font-weight: bold;
    color: #facc15;
}

.quote-close-btn {
    width: 100%;
    margin-top: 10px;
    font-size: 1.05rem;
    box-shadow: 0 8px 20px rgba(99, 102, 241, 0.3);
}
```
