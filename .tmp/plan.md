# [CEO 기획 보고] 스마일Again 배경 비디오 교체 기획안

## 1. 핵심 요약
- 앱의 본래 이름인 **'스마일Again'** 브랜딩을 100% 그대로 유지하고 독립된 앱으로서 안정적인 환경을 다집니다.
- 잠금화면(Gateway)의 배경 비디오를 기존 `솔이-2_.mp4`에서 리소스 폴더의 명물인 **`솔이 뼈다구.mp4`**로 교체하여 더 활기차고 매력적인 첫인상을 제공합니다.
- 다른 복잡한 기능 추가나 코드 수정 없이, 요청하신 비디오 교체 작업만을 안전하게 진행하여 완벽한 안정성을 보장합니다.

## 2. 사용자 경험
- **[진입 화면 비디오 교체]**: 사용자가 앱을 켜면, 기존의 '솔이-2' 영상 대신 꼬리를 치고 뼈다귀 장난감을 가지고 노는 **'솔이 뼈다구'**의 생생하고 귀여운 고화질 영상이 잠금화면 전체에 무한 반복(Loop) 재생됩니다.
- 미소를 활짝 지으면 꽃가루 Confetti 축포와 함께 부드럽게 잠금이 해제되며 본 서비스로 진입하는 핵심 경험은 고스란히 유지됩니다.

## 3. 리스크 알림
- **비디오 파일명 공백 문제 (CORS 및 웹 표준)**: `솔이 뼈다구.mp4`와 같이 파일명에 띄어쓰기(공백)가 있을 경우, 모바일 기기 브라우저나 서비스 워커(Service Worker)가 파일을 정상적으로 인식하지 못하고 엑스박스나 로딩 지연이 발생할 수 있습니다.
- **해결책**: 원본 `resources/솔이 뼈다구.mp4`를 루트 폴더에 복사할 때, 띄어쓰기를 없앤 **`솔이_뼈다구.mp4`** 또는 **`sol_bone.mp4`**로 파일명을 매끄럽게 보정하여 복사한 뒤 적용하겠습니다.

## 4. 선택지 제안

### A안 (최선책) - 비디오 파일명 안전 인코딩 보정 적용 (추천)
- **내용**: 리소스의 `솔이 뼈다구.mp4`를 가져올 때, 파일명 공백을 언더바로 치환한 `솔이_뼈다구.mp4`로 복사하여 `index.html` 및 `sw.js` 캐싱 리스트에 완벽하게 바인딩합니다.
- **이유**: 모바일 브라우저 및 PWA 환경에서 한글 공백으로 인한 로딩 오류(404 or Decode Error)를 100% 원천 차단합니다.

### B안 (차선책) - 공백을 그대로 유지하여 복사
- **내용**: `솔이 뼈다구.mp4` 파일명 공백을 그대로 유지한 채 루트로 가져와 연결합니다.
- **단점**: 일부 모바일 기기(아이폰 사파리 등)에서 동영상이 로드되지 않고 검은 화면만 지속될 위험이 높습니다.
