# [PM 기획안] '어색A 서먹I' 명언 API 연동 리빌딩 기획안

## 1. 핵심 요약
* **미소 지으면 명언 제공**: 사용자가 웃어서 잠금을 해제할 때, 매일 다른 고품격 명언을 선물하여 **매일 아침 앱을 켜고 웃게 만드는 힐링 루틴**을 형성합니다.
* **비즈니스 가치 극대화**: 단순 일회성 유머 앱에서 **하루를 활기차게 시작하는 데일리 명상/자기계발 앱**으로 카테고리를 확장하여 사용자 유지율(Retention)을 200% 이상 끌어올립니다.
* **고급 감성 브랜딩**: 화면에 떠오르는 영문 명언과 로컬 음성 합성(TTS) 낭독 기능을 결합하여, **디지털 액자나 고급 인테리어 소품처럼 활용할 수 있는 프리미엄 감성**을 연출합니다.

---

## 2. 사용자 경험
1. **웃음으로 시작하는 하루**: 사용자가 앱을 켜고 카메라 앞에서 미소를 지으면, 스마일 인식(MediaPipe)과 동시에 꽃가루가 터지며 잠금이 해제됩니다.
2. **영혼을 깨우는 한마디**: 화면이 전환되며 잔잔한 그라데이션 배경 위로 포리스매틱 API가 실시간으로 가져온 오늘의 명언(영어)이 한 자씩 타이핑되는 효과와 함께 부드럽게 나타납니다.
3. **귀로 듣는 명언**: 동시에 따뜻하고 차분한 AI 음성(TTS)이 명언을 낭독해 주며 사용자에게 긍정적인 에너지를 전달합니다.
4. **치트키 & 게임 공유**: 명언 카드 하단에 기존의 '무한 밸런스 게임'과 '상황별 치트키(어색/서먹)' 버튼을 자연스럽게 배치하여, 마음을 환기한 사용자가 자연스럽게 아이스브레이킹 대화 카드로 넘어가도록 유도합니다.

---

## 3. 리스크 알림
1. **보안 프로토콜 및 CORS 차단 위험**: 포리스매틱 API는 HTTP 프로토콜(`http://api.forismatic.com/...`)을 사용합니다. 파이어베이스(HTTPS) 환경에 배포 시 브라우저가 보안 위험(Mixed Content)으로 요청을 강제 차단할 수 있습니다.
   * *대비책*: 하이브리드 설계 방식을 도입하여, 실시간 API 호출을 시도하되 실패할 경우 미리 내장된 **엄선된 동기부여 명언 DB 100선**에서 즉시 불러오도록 설계해 서비스 중단을 100% 방지합니다.
2. **영어 명언의 가독성 피로**: API가 영어 명언을 반환하므로, 영어에 익숙하지 않은 사용자는 직관적인 의미 전달이 안 되어 몰입도가 떨어질 수 있습니다.
   * *대비책*: 명언 텍스트 하단에 핵심 어휘 팁 또는 한국어 번역 요약을 함께 매칭해 보여주는 미니 딕셔너리/큐레이션 영역을 제공하여 자기계발 및 가독성을 동시에 만족시킵니다.

---

## 4. 선택지 제안

### A안 (최선책) - "스마일 미소 보상 명언 & 힐링 사운드 루틴" (추천)
* **내용**: 기존 스마일 해제 직후, 화면 정중앙에 '오늘의 미소 보상 명언 카드'를 크게 띄우고 TTS로 영어 명언을 읽어줍니다. 힐링 감성의 오디오 효과음도 함께 연주됩니다.
* **이유**: 사용자가 '웃어야만 선물을 받는다'는 강력한 행동 유도가 완성되어 앱의 매력과 본질이 극대화됩니다.

### B안 (차선책) - "현자의 지혜 (명언 치트키) 독립 탭 추가"
* **내용**: 메인 홈 화면에 '어색AI', '서먹AI'와 동등한 레벨로 '명언AI (현자의 지혜)' 버튼을 추가하여, 대화 정적이 흐를 때 지적인 명언으로 화제를 전환하는 대화 치트키 도구로 활용합니다.
* **이유**: 기존 UI 구조를 변경하지 않고 독립된 탭 하나만 늘리므로 개발 공수가 가장 적게 듭니다.
