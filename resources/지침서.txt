너는 지금부터 내가 제공한 `index.html` 코드를 바탕으로 "어색A 서먹I"라는 새로운 아이스브레이킹 앱을 리빌딩하는 수석 개발자야. 
내가 제공한 `humorData` 배열(60개 데이터)을 사용해서 아래 3단계 지시사항을 정확히 수행해 줘.

[절대 규칙]
기존 HTML의 <style> 태그 안에 있는 CSS(유리 질감, 그라데이션, 애니메이션, 로더 등)는 단 한 줄도 건드리지 말고 100% 그대로 유지할 것. 디자인은 절대 바꾸지 마.

[1단계: UI 텍스트 교체]
1. <h1> 태그의 "Daily Humor"를 "어색A 서먹I"로 변경해.
2. <button> 태그의 "Get Another Joke"를 "상황별 치트키 뽑기"로 변경해.
3. 데이터 출력을 위해 HTML 구조를 살짝 수정해: 
   - <div id="setup">에는 `situation` (상황)과 `guide` (대처 가이드)를 보여줘.
   - <div id="punchline">에는 `joke` (실전 멘트)를 보여줘.

[2단계: 데이터 소스 및 로직 교체]
1. <script> 태그 안의 `fetch('https://official-joke-api.appspot.com/random_joke')` 관련 외부 API 호출 로직을 완전히 삭제해.
2. 그 자리에 내가 준 `humorData` 배열 전체를 삽입해.
3. 버튼을 누르면 `humorData` 배열에서 무작위(Random)로 데이터 하나를 뽑아오는 함수를 만들어.

[3단계: 애니메이션 연동]
1. 버튼을 누르면 기존처럼 로더(loader)가 1~1.5초 정도 빙글빙글 돌게 해. (앱이 상황을 분석하는 듯한 효과 연출)
2. 로딩이 끝나면 뽑힌 데이터의 `situation`과 `guide`가 먼저 화면에 나타나고, 1.5초 뒤에 기존 CSS의 opacity 효과(.show 클래스)를 이용해 `joke`가 부드럽게 나타나도록 타이밍을 맞춰 줘.

위 지시대로 완벽하게 수정된 전체 코드를 하나로 통합해서 출력해 줘.
